# 2026-11-07 main 통합 변경

## 반영 범위

- 권한별 관리 화면 접근, 종결 이용자 통계, 이름 변경 후 입력/목록 갱신, 오류와 실제 0건 표시 구분.
- 반응은 참여 정도 1개 + 기타 별도 선택. 활동 시간은 시작·종료를 각각 분 단위로 선택하고 종료 24:00을 지원.
- 일별·월별 보고서에 저장된 완료 일지와 실제 작성자 정보를 연결. 없는 결과 문구를 생성하지 않으며, 입력할 수 없는 목표·평가 등의 칸은 사용자 결정대로 제거.
- 보고서의 건수·행동 영역 표기, 출력 기간 검사, 이어지는 표의 머리글 반복, 실제 다운로드 검증.
- 설치·현재 동작 문서·자동 검사와 사용자 매뉴얼 PDF 및 제작 도구 추가.

## 원격 main 변경과 통합

FE `c9ccbda` 및 BE `2fa54c2`까지의 새 main 커밋 이력을 보존하면서 통합했다.

- 새 main의 짧은 통계 카드 이름, 글줄 정리, 주간 날짜 범위 표시를 반영했다.
- 통계 기본 활동 선택은 사용자가 선택한 값을 유지하되 이용자·조회 범위가 바뀌면 유효한 최다 기록 활동을 선택하는 구현을 사용한다.
- 주차 계산은 앞서 확정한 **일요일~토요일 7일 전체**를 FE·BE 모두에 적용한다. 새 main의 ‘월 안에서 자르고 하루짜리 주를 붙이는’ 규칙과 충돌한 부분은 이 확정 정책으로 맞췄다.
- 주간 날짜 표시는 월·연 경계에서도 혼동하지 않도록 실제 시작·종료 날짜를 모두 표시한다. 새 main의 주차 검사도 7일 정책에 맞게 갱신했다.

## 검증

원격 main 통합 후 아래 검사를 다시 실행해 모두 통과했다.

| 검사 | 결과 |
|---|---|
| FE 전체 회귀 검사 | 372개 성공, 실패·건너뜀·불안정 재시도 0 |
| BE 전체 검사 | 204개 성공, 실패·오류·건너뜀 0. 임시 PostgreSQL 통합 검사 포함 |
| FE 배포 빌드·데이터/DOCX 검사 | 성공 |
| BE bootJar 빌드 | 성공 |
| FE 배포 빌드에서 보고서 출력 | 23개 성공 |
| S22급 모바일 매뉴얼 절차·화면 캡처 | 16개 성공. 최신 화면으로 PDF 재생성 |

FE 372개 + BE 204개는 576개이며, 배포 출력 23개와 매뉴얼 16개는 별도 실행 결과다. 브라우저 검사는 제어한 API 응답을 사용하고, 실제 SQL은 임시 PostgreSQL에서 검사했다. 운영 사용자 자료를 변경한 검사가 아니다.

## 배포 구성

프론트는 Vercel 구성(`vercel.json`)을 사용하고 `/api`를 BE 도메인으로 전달한다. BE는 main push 시 GitHub Actions의 테스트가 성공한 뒤 AWS EC2에 자동 배포하는 설정이다. 소스 반영과 실제 배포 성공 여부는 별도로 확인한다.
