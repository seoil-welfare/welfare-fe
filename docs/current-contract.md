# 현재 FE·BE 계약 — 2026-11-07

이번 점검 수정의 기준이다. `backend-integration.md`의 이전 가정·제안보다 이 문서와 실제 API 타입을 우선한다.

## 인증·계정

- `POST /api/auth/login`의 autoLogin이 true면 서버 세션·쿠키를 30일, false/누락이면 서버 세션 1시간·세션 쿠키로 발급한다. HttpOnly, SameSite=Lax이며 HTTPS 요청은 Secure이다. 로그아웃·비밀번호 변경은 세션과 쿠키를 삭제한다. 서버 재시작 뒤 세션 복원 기능은 없다.
- 비밀번호는 8자 이상·영문/숫자 포함·공백 금지·UTF-8 72바이트 이하. 변경 후 다시 로그인한다.
- 회원가입 없음. `POST /api/staff`는 팀장·국장만, staff 역할로만 만든다. 응답 temporaryPassword를 팝업으로 한 번 보여 준다. 아이디는 소문자로 정규화하고 `[a-z0-9._-]{4,50}`로 검사한다.
- `/staff`, `/staff/new`, `/staff/:id`, `/settings/participation` 화면은 팀장·국장만 연다. 실제 관리 작업도 서버가 검사한다. `GET /api/staff`는 기존 화면의 작성자·담당자 표시를 위해 로그인한 직원에게 제공한다.

## 이용자

| API | 규칙 |
|---|---|
| GET /api/service-users | 로그인한 직원. 종결 포함 |
| POST /api/service-users | 로그인한 직원. 등록 |
| PUT /api/service-users/:id | 로그인한 직원. 정보 수정 |
| POST /api/service-users/:id/close | 팀장·국장만. closed로 바꾸고 closed_at 기록 |
| POST /api/service-users/:id/reopen | 팀장·국장만. active로 바꾸고 closed_at 비움 |

종결·재개는 같은 이용자 ID를 유지한다. 일지와 통계는 삭제하지 않는다. 같은 상태 요청은 안전하게 현재 값을 돌려준다. 종결 이용자 상세와 통계의 종결 이용자 포함으로 과거 기록을 조회한다.

## 일지·활동

- 이용자·날짜당 1건, 미래 날짜 저장 금지. 작성 중 → 완료는 가능하지만 완료 → 작성 중은 불가.
- 작성 중은 작성자만 수정. 작성 중 삭제는 작성자 또는 팀장·국장. 완료 일지는 삭제 불가.
- POST/PUT 저장은 전체 활동 목록을 받는다. PUT은 updatedAt 필수이며 서버가 행을 잠근 후 버전을 비교한다. 충돌은 409 DIARY_UPDATED_BY_OTHER이다.
- 임시저장은 실제 서버 draft 저장. 자동저장은 입력 후 2초 또는 화면 가려짐 시 동작하며 완료 일지 수정은 자동저장하지 않는다. 미저장 새로고침·탭 닫기는 경고한다. 기기에 일지 내용은 저장하지 않고 복원용 ID만 sessionStorage에 둔다.
- 활동 시작 `00:00~23:59`, 종료 `00:01~24:00`, HH:mm 분 단위. 종료가 시작보다 늦고 다른 활동과 겹치지 않아야 한다. 작성 중 시간 미입력은 허용하지만 완료에는 필수. 자정 넘김은 날짜별로 나눠 기록한다.
- BE는 24:00을 1440분으로 검사하고 PostgreSQL TIME의 24:00:00으로 저장한다. JDBC LocalTime으로 읽어 00:00이 되지 않도록 문자열로 조회한다. 기존 TIME 컬럼·종료>시작 제약을 유지하므로 새 스키마 마이그레이션은 없다.
- 이용자 반응은 참여 정도 1개 + 기타 별도 허용. 같은 참여 정도 중복은 서버가 한 번으로 처리하고 서로 다른 참여 정도 둘 이상은 거절한다. 과거 복수 선택은 하나를 다시 골라 저장한다.
- 도전적 행동이 선택된 완료 활동은 유형별 세부 행동이 필요하다. 상위 기타는 직접 입력이 필요하다.
- 참여 활동은 DB 항목 ID로 보존하고 응답 시 현재 이름으로 표시한다. 항목 변경 후 일지·통계·선택지 캐시를 갱신한다.
- 사전 지원·긍정행동지원의 선택지 제공 표기를 통일했다. 서버는 이전의 공백 없는 입력도 호환한다.

## 통계·출력

- 통계는 `/api/stats/summary`에서 완료 일지만 집계한다. 이전 기간의 완료 일지가 0건일 때만 previousEmpty이다.
- 주차는 월과 만나는 일요일~토요일 7일 전체이다. 이전 기간은 실제 시작일의 7일 전이며, 추이 구간은 겹치지 않는다. 같은 주가 이웃 월의 선택지에도 나타날 수 있지만 단일 통계의 비교·추이에는 중복되지 않는다.
- 활동별 반응의 기본 선택은 참여 기록이 가장 많은 유효한 활동이다. 사용자가 같은 이용자·기간 안에서 명시적으로 고른 0건 활동은 유지한다. 조회 범위가 바뀌면 기본 선택을 다시 결정한다.
- 종결 이용자는 기본 목록에서 숨기고 종결 이용자 포함을 선택하면 조회할 수 있다. `/stats?userId=:id&includeClosed=true`로 바로 연다.
- 없는 통계 분류는 404 안내 화면. 실패·로딩 중에는 완료 일지 0건 기준 문구를 숨긴다.
- 동일 활동의 동일 유형·세부 행동은 1건, 내용 없는 상위 기타는 0건이다. FE 통계·일일/월간 출력은 behaviorEntries를 공통 사용한다.
- 출력 숫자 단위는 건, 월간 행동 이름에 영역을 표시한다. 일지 모음은 오늘까지 최대 92일이다.
- 출력 메뉴는 일별활동일지/월별활동일지이다. 제공된 양식의 미입력 항목은 제거하고 저장된 완료 일지만 사용한다. 행동 건수는 선택 기록 수이며 결과·평가·실제 발생 횟수를 추정하지 않는다. 특이사항 원문과 일지 작성자 이름을 출력한다.

## 검증

- FE `npm run verify`, `npm run test:qa`.
- BE `./gradlew test` (Windows `gradlew.bat test`). JUnit 권한·규칙 검증과 임시 PostgreSQL 통합 검증을 포함한다. Embedded PostgreSQL 테스트 도구는 [공식 프로젝트](https://github.com/zonkyio/embedded-postgres)를 사용한다.
- 브라우저 회귀 검증의 API 응답 제어와 실제 DB 통합 검증은 서로 다른 범위다. 실기기 키보드·스크린 리더·운영 서버 배포 검증은 별도다.
